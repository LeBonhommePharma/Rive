# Rive refinement and browser verification — 2026-09-06

This pass preserves the current layout, typography and Le Bonhomme palette. It improves the existing interface and adds regression coverage for problems observed in use.

## What changed

- Persistent departure/destination labels, separate accessible input labels, and 44 px clear buttons that return focus to the edited field.
- Search results support arrows, Home/End, Escape, and reopening after dismissal. Public stop codes distinguish stops with identical names.
- Selecting a stop or route invalidates an older pending/displayed journey. Late responses cannot restore that superseded journey.
- Route exploration includes ordinary bus routes when a city has no metro or 800-series routes.
- Selecting a route frames its full geometry. On phones, the panel folds to reveal the map and keeps keyboard focus on a clearly labelled details button. The skip link reopens search from that state.
- Route endpoints wrap instead of being truncated. Map controls match the palette, have French accessible labels, and remain clear of the open phone panel.
- Compact landscape confirmation controls sit below the location target instead of covering it.
- Background atlas updates preserve map exploration and an in-progress destination search.
- Atlas sections, controls, search metadata and feedback use the selected language consistently; regional locales inherit missing entries from their base language.
- The atlas outer panel clips without becoming a scroll container, leaving search scrolling to its inner panel and keeping the toolbar visible.

## Automated verification

- **258 tests passed, 0 failed, 0 skipped**, including 18 main-app interaction tests,5 map-effect tests and 29 atlas-controller tests.
- Production build passed with `npm run build -- --webpack` in an isolated source copy.
- ESLint: **0 errors, 5 existing unused-variable warnings**. Changed TypeScript/JavaScript files also passed focused lint/type checks.
- `git diff --check` passed.
- Existing MapLibre package-JSON named-export build warning remains.
- Tests use controlled browser/network/location callbacks for cancellation, late responses, background updates, language fallback and camera ordering. They do not substitute for the actual browser checks above.

Browser logs retained one development hot-reload warning while effect dependencies were edited. No new error entries were captured during the subsequent production checks.

The production preview ran locally on port 3002 from an isolated copy. [Source manifest](polish-source-manifest.json) records the copied files and their SHA-256 hashes. The final static atlas stylesheet was synchronized after the toolbar clipping correction; the compiled app was unchanged.

## Limits

Real GPS acquisition remains unverified from the previous pass: the in-app browser did not return device coordinates. This pass does not claim a new successful GPS fix. Physical iPhone/iPad, separate Safari/Chrome, a complete screen-reader audit and live deployment were not tested or performed. Background update races were verified using controlled tests, not a live GPS stream.
